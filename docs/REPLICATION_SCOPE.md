# Scope and limits

The runner recreates the primary RQ1/RQ2 models, agent-family models,
time-aware models, calendar support, and repository influence checks.
It compares the corresponding archived model CSVs with a relative tolerance
of 1e-7 and absolute tolerance of 1e-8. Raw ZIP archives retain
model input tables and logs. The readable reference folders extract the
small result tables, excluding large intermediate data.

This is model-level replication from frozen inputs, not a complete
re-download of AIDev and GitHub. The added RQ2 review-terms model comparison,
Figure 2 repository ratios, Claude detection audit, the exploratory
excluded-PR analysis, and the special Cursor leave-one-repository-out check
are not generated by this main runner. Where available, separately archived
tables are marked as references and are not counted among the model CSVs
checked by `verify_results.py`.

The `repository_descriptives.csv`, frozen analysis contract, and
repository-sampling code are copied when available. Their presence or
absence is recorded in `config/source_manifest.json`; the model-level
rerun does not require them.
